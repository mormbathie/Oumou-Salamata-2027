Utilisez votre propre compte. Le nom de la personne qui inscrit un élève, crée une facture, encaisse un paiement ou effectue un pointage peut être affiché sur les fiches concernées.

Se connecter et prendre ses repères

Quelques gestes pour bien commencer.

Tous les utilisateurs
  1. Ouvrez https://assakina-school.com dans votre navigateur.
  2. Choisissez Français, English ou العربية dans le sélecteur de langue.
  3. Saisissez l’identifiant et le mot de passe remis par l’administrateur.
  4. Appuyez sur Se connecter. Lors de votre première connexion, suivez la demande de changement de mot de passe.

Comprendre l’écran

Le menu donne accès aux différentes rubriques. Sur un téléphone, utilisez le bouton du menu pour l’ouvrir. Votre nom et votre rôle vous permettent de vérifier le compte utilisé.

Changer de langue

Votre choix est conservé dans ce navigateur. L’arabe se lit de droite à gauche. Le changement de langue recharge l’écran : enregistrez d’abord vos modifications.

En quittant un appareil partagé

Utilisez le bouton de déconnexion près de votre nom. Fermer simplement l’onglet ne remplace pas la déconnexion.

Mon profil et mon mot de passe

Gardez vos coordonnées à jour.

Tous les utilisateurs

Modifier ses informations

Ouvrez Mon profil. Vérifiez votre prénom, votre nom, votre adresse e-mail et votre téléphone. Corrigez les champs souhaités, puis appuyez sur Enregistrer le profil.

  1. Ouvrez Mon mot de passe ou Changer mon mot de passe depuis le profil.
  2. Saisissez le mot de passe actuel. À la première connexion, il s’agit du mot de passe provisoire reçu.
  3. Choisissez un nouveau mot de passe d’au moins 8 caractères, puis saisissez-le une seconde fois.
  4. Appuyez sur Changer mon mot de passe. Utilisez ensuite le nouveau mot de passe pour vous connecter.
Mot de passe oublié

Sur l’écran de connexion, choisissez Mot de passe oublié ?, saisissez votre adresse e-mail et ouvrez le lien reçu. Si vous n’avez plus accès à cette boîte, contactez l’administrateur.

Vérifier son adresse e-mail

Utilisez Envoyer un lien de vérification, puis ouvrez le message reçu et suivez son lien. Consultez aussi les courriers indésirables. Une modification de l’adresse nécessite une nouvelle vérification.

Disponibilité des fonctions

L’envoi des e-mails est activé. Vous pouvez activer la double authentification depuis votre profil après vérification de votre adresse. Les étapes détaillées figurent à la fin du guide.

Préparer les classes et les matières

À faire avant les premières inscriptions.

Administrateur et directeur

Créer une classe

Ouvrez Classes & Matières, puis Créer une classe.

  1. Donnez un nom à la classe, par exemple « CP A », puis choisissez son niveau.
  2. Indiquez l’effectif maximal, les frais d’inscription et la scolarité mensuelle en FCFA.
  3. Sélectionnez l’enseignant responsable si son compte existe déjà. Vous pouvez l’affecter plus tard.
  4. Vérifiez les montants, puis validez la création.

Modifier une classe

Sur la carte de la classe, utilisez Modifier la classe, corrigez les informations et enregistrez. Le choix Affecter un enseignant permet également de désigner le responsable.

Ajouter ou modifier une matière

Utilisez Ajouter une matière. Renseignez le nom, un code court et le coefficient. Le coefficient donne plus ou moins de poids à la matière dans la moyenne. Pour corriger une matière existante, utilisez Modifier dans sa ligne.

Ordre conseillé

Créez les comptes enseignants, préparez les classes et leurs tarifs, puis inscrivez les élèves. Si aucune année scolaire n’existe, la première classe initialise l’année scolaire.

Inscrire un nouvel élève

Préparez les informations de l’enfant et de son responsable.

Administrateur, directeur et comptable
  1. Ouvrez Inscriptions & Élèves, puis Nouvelle inscription.
  2. Renseignez les prénoms, le nom, le sexe, la date et le lieu de naissance. Complétez les autres informations utiles si vous les connaissez.
  3. Choisissez la classe dans laquelle l’enfant est inscrit.
  4. Sélectionnez un parent déjà enregistré, ou renseignez un nouveau parent : identité, téléphone et adresse e-mail si disponible.
  5. Vérifiez l’option de création de la facture d’inscription et les informations saisies.
  6. Validez l’inscription. Les documents peuvent être ajoutés ensuite dans le dossier.
Avant de créer le dossier

Recherchez d’abord l’enfant par son nom ou son matricule pour éviter une double inscription. Vérifiez aussi la date de naissance affichée et le numéro du parent.

Après l’inscription

Retrouvez l’élève dans la liste, puis ouvrez Dossier. Son matricule permet de le reconnaître sans confusion. La fiche peut aussi indiquer le nom de la personne ayant réalisé l’inscription.

6

Consulter et compléter un dossier

Une fiche pour retrouver le suivi de chaque élève.

Tous les utilisateurs
  1. Dans Inscriptions & Élèves, recherchez le nom ou le matricule. Validez la recherche.
  2. Si le filtre est disponible, choisissez une classe pour réduire la liste.
  3. Appuyez sur Dossier à côté de l’enfant.
  4. Consultez ses informations, ses inscriptions et les éléments de suivi disponibles pour votre rôle.

Corriger une information

L’administrateur et le directeur disposent du bouton Modifier dans le dossier. Corrigez les renseignements de l’élève ou du parent proposés à l’écran, puis enregistrez.

Ajouter les pièces du dossier

Pour la direction et l’administrateur, l’onglet Documents permet d’ajouter les pièces de l’élève et du parent : extrait de naissance, photo, carnet de vaccination, certificat médical, ancien bulletin, pièce d’identité ou passeport.

  1. Choisissez la rubrique du document et appuyez sur Ajouter un fichier.
  2. Sélectionnez un fichier lisible : PDF ou image compatible avec la rubrique, de 10 Mo maximum.
  3. Attendez la fin de l’envoi. Pour récupérer une pièce, utilisez son bouton de téléchargement.
Supprimer avec précaution

La direction et l’administrateur peuvent disposer d’actions de suppression. Ne les utilisez pas pour corriger une simple faute de saisie : préférez Modifier. Ne confirmez une suppression qu’après vérification.

Parents et accès des familles

Rattacher chaque enfant au bon responsable.

Équipe administrative et parents

Enregistrer un parent

Dans Parents d’élèves, utilisez Ajouter un parent. Indiquez les prénom et nom, le téléphone, puis les autres renseignements utiles : e-mail, lien avec l’enfant, profession et adresse. Enregistrez la fiche.

Retrouver une famille

Recherchez par nom, téléphone ou e-mail. L’annuaire affiche les coordonnées et les enfants rattachés au responsable. Pour corriger les informations d’un parent lié à un élève, la direction peut utiliser la modification du dossier de cet élève.

Fiche parent et compte de connexion

Enregistrer un parent dans l’annuaire ne crée pas automatiquement son compte de connexion. L’administrateur doit créer un compte avec le rôle Parent. Son adresse e-mail doit correspondre à celle du parent enregistré pour retrouver ses enfants.

Pour les parents

Connectez-vous avec votre compte personnel, puis ouvrez Inscriptions & Élèves et le Dossier de l’enfant. Consultez les informations scolaires, les notes et bulletins disponibles, les présences et les factures affichées. Les paiements sont enregistrés par l’école ; l’écran n’effectue pas de paiement en ligne.

Un enfant n’apparaît pas ?

Contactez l’école et indiquez son nom ainsi que votre adresse e-mail de connexion. L’école vérifiera le rattachement du dossier.

Factures, paiements et reçus

Suivre les montants facturés, encaissés et restant à payer.

Administrateur, directeur et comptable

Créer les factures mensuelles

Ouvrez Factures & Paiements, puis le bouton de génération des factures de scolarité par classe. Choisissez la classe, le mois ou le libellé et la date limite de paiement. Vérifiez le tarif de la classe, puis générez les factures. Elles concernent les élèves inscrits de cette classe.

  1. Recherchez la facture avec les filtres de classe et de statut. Vérifiez le nom de l’élève et le montant restant.
  2. Appuyez sur Payer pour enregistrer un paiement déjà reçu par l’école.
  3. Indiquez le montant réellement encaissé et le moyen de paiement : espèces, Wave, Orange Money, virement ou chèque.
  4. Ajoutez la référence de transaction si nécessaire, ainsi qu’une observation utile.
  5. Vérifiez la saisie, puis appuyez sur Confirmer l’encaissement.
Un enregistrement, pas un transfert d’argent

Choisir Wave ou Orange Money sert à indiquer comment l’école a reçu le paiement. Ce bouton ne débite pas le compte du parent.

Remettre un reçu

Après l’encaissement, consultez le reçu. Le bouton Reçu permet aussi de retrouver le dernier reçu disponible sur une facture. Utilisez Imprimer / enregistrer PDF, puis choisissez une imprimante ou l’option PDF proposée par votre appareil.

Statut de factureSignification

Exemple fictif

Une facture de 25 000 FCFA et un versement de 10 000 FCFA donnent un reste à payer de 15 000 FCFA. Enregistrez le versement réel, pas le montant total de la facture.

Utiliser le tableau de bord

Ouvrez Tableau de bord pour consulter les indicateurs affichés : effectifs, situation financière et suivi de l’école. Pour vérifier un détail ou effectuer une action, ouvrez ensuite la rubrique correspondante.

Savoir qui a effectué l’action

Les nouvelles fiches et certains reçus affichent l’agent concerné lorsqu’il a été enregistré. Les anciennes fiches peuvent ne pas comporter ce renseignement. Pour signaler une erreur, communiquez le numéro de facture ou de reçu à la direction.

Saisir les notes et préparer les bulletins

Travaillez toujours sur la bonne classe et le bon trimestre.

Enseignant, directeur et administrateur
  1. Ouvrez Notes & Bulletins, puis l’onglet de saisie des notes.
  2. Choisissez la classe, le trimestre, la matière et le type d’évaluation.
  3. Saisissez les notes sur 20 et les appréciations utiles pour les élèves concernés.
  4. Relisez les lignes, puis appuyez sur Enregistrer les notes.

Corriger une note

Sélectionnez à nouveau la même classe, le même trimestre, la même matière et le même type d’évaluation. Corrigez la valeur affichée, puis enregistrez. Ne confondez pas une note manquante avec une note de zéro.

Calculer les bulletins

La direction ou l’administrateur ouvre l’onglet des bulletins du trimestre et utilise Générer / Recalculer les bulletins. L’application calcule les résultats à partir des notes enregistrées et des coefficients des matières.

Consulter et imprimer

Utilisez Voir le bulletin pour vérifier les notes, les moyennes, les appréciations et le rang. Le bouton Imprimer le bulletin ouvre les options d’impression de votre appareil.

Avant de remettre les bulletins

Contrôlez les notes et l’identité de l’élève. Après une correction de note, demandez à la direction de recalculer les bulletins afin que le document reflète la modification.

Présences des élèves : la feuille de classe

Enregistrer ou corriger la présence d’une journée.

Enseignant, directeur et administrateur
  1. Ouvrez Présences & Absences.
  2. Choisissez la classe et la date à traiter. Vérifiez ces deux informations avant de saisir.
  3. Pour chaque élève, choisissez Présent, Absent, En retard ou Excusé.
  4. Ajoutez le motif ou la remarque utile lorsqu’un élève est absent ou excusé.
  5. Appuyez sur Enregistrer les présences et attendez le message de confirmation.

Si toute la classe est présente

Le bouton Tout marquer présent remplit rapidement la feuille. Corrigez ensuite les exceptions éventuelles, puis enregistrez.

Vérifier ou corriger une journée

Rouvrez la même classe et la même date. Relisez les statuts, modifiez les lignes concernées et enregistrez à nouveau.

Vérifier la journée scolaire

Ne renseignez pas d’absences pour une journée où l’école est fermée. Le calendrier des professeurs est décrit à la page 15 ; il ne remplace pas la vérification de la date de la feuille des élèves.

Scanner les élèves au portail

Une présence enregistrée sans choisir la classe à chaque scan.

Contrôleur de présence, directeur et administrateur
  1. Ouvrez Scanner les QR codes sur le téléphone du contrôleur.
  2. Autorisez l’application à utiliser la caméra. Orientez la caméra arrière vers le QR code de l’élève.
  3. Tenez le code entier dans l’image, avec une lumière suffisante. Attendez la confirmation.
  4. Vérifiez le nom de l’élève, sa classe et le résultat affiché avant de passer au suivant.

Où trouver le QR code ?

Le QR code de l’élève est disponible dans son dossier. L’école peut le présenter sur un écran ou préparer une carte lisible pour le contrôle. Chaque enfant doit utiliser son propre code.

Retrouver une classe ou saisir un code

Le choix d’une classe sert à consulter sa liste de présence ; il n’est pas nécessaire pour identifier l’élève lors du scan. Si la caméra est indisponible, utilisez le champ de saisie manuelle prévu à l’écran.

Clôturer les absences

Après les arrivées, vérifiez les élèves non pointés et les justificatifs connus. La clôture peut marquer absents les élèves sans pointage. Choisissez soigneusement la portée proposée : classe ou ensemble des classes. Ne clôturez pas avant la fin des arrivées ni un jour de fermeture.

Pour un scan rapide

Nettoyez l’objectif, évitez les reflets et éloignez légèrement le téléphone si le code ne rentre pas dans l’image. Un code inconnu doit être vérifié auprès de l’administration.

Pointage des professeurs et calendrier

Enregistrer les arrivées et départs, sans absenter les jours de repos.

Professeur, contrôleur et direction

Pour le professeur

Ouvrez Mon profil et présentez votre QR code personnel au contrôleur à votre arrivée, puis à votre départ. Dans Mon pointage, consultez les dates, heures d’arrivée et de départ, statuts, minutes de retard et le contrôleur indiqué.

  1. Le contrôleur ouvre Pointage des professeurs et active la caméra si nécessaire.
  2. Il scanne le QR code personnel du professeur à l’arrivée et vérifie la confirmation.
  3. Au départ, il scanne à nouveau le même QR code et vérifie que le départ est enregistré.
  4. Il consulte la liste de la journée pour contrôler les pointages. Un code peut aussi être saisi manuellement.
Deux passages distincts

Le premier scan enregistre l’arrivée ; le suivant peut enregistrer le départ. Ne rescanez pas inutilement un professeur qui vient d’arriver. Vérifiez toujours le message affiché.

Préparer les jours travaillés

La direction ou l’administrateur règle le Calendrier de travail : jours de repos, heure de début et fuseau horaire. Pour les jours de repos, 0 correspond au dimanche et 6 au samedi. Enregistrez les réglages, puis ajoutez les dates et noms des jours fériés ou fermetures.

Clôturer les absences des professeurs

Après vérification de la liste du jour, utilisez la clôture des absences pour les professeurs sans arrivée enregistrée. La clôture est refusée pour un jour de repos, un jour férié ou une date future. Le retard est calculé par rapport à l’heure de début configurée.

Gérer les comptes de l’équipe

Donner à chaque personne le bon accès.

Administrateur uniquement
  1. Ouvrez Gestion des utilisateurs, puis le bouton d’ajout d’un utilisateur.
  2. Renseignez son identifiant, son prénom, son nom et une adresse e-mail correcte.
  3. Choisissez le rôle correspondant à sa mission, puis un mot de passe provisoire.
  4. Validez la création et remettez les informations de connexion à la personne concernée.
  5. Demandez-lui de changer son mot de passe lors de sa première connexion.

Modifier les informations et le rôle

Utilisez l’action Modifier sur le compte concerné. Vérifiez l’adresse e-mail et le rôle avant d’enregistrer. Pour les parents, l’adresse doit correspondre à celle de leur fiche parent. Pour les professeurs, affectez ensuite leur compte à la bonne classe.

Réinitialiser un mot de passe

Utilisez l’action de réinitialisation du compte. Définissez un nouveau mot de passe provisoire et transmettez-le à la bonne personne. Son changement sera demandé à la prochaine connexion.

Désactiver ou supprimer

La désactivation bloque l’accès du compte. Utilisez-la lorsqu’une personne ne doit plus se connecter. La suppression est une action différente : vérifiez le compte et les conséquences avant de confirmer.

Choisir un rôle avec soin

Ne donnez pas le rôle administrateur par défaut. Chaque personne doit avoir les accès utiles à son travail, avec son propre identifiant.

15

Exporter ou importer un fichier

Fonction réservée à la personne chargée des données de l’école.

Administrateur uniquement

Exporter vers Excel

Dans Import / export, utilisez Toutes les tables · Excel. Le fichier téléchargé contient plusieurs feuilles : élèves, classes, matières, inscriptions, factures, paiements, notes, présences et autres catégories scolaires proposées.

Exporter une seule catégorie

Choisissez la catégorie dans la liste, puis Table choisie · CSV. Un CSV contient une seule catégorie de données.

  1. Partez d’un fichier exporté pour conserver les bonnes colonnes et les bons noms de feuilles.
  2. Préparez le fichier avec la personne responsable des données. Ne changez pas au hasard les codes qui relient les fiches entre elles.
  3. Sélectionnez le fichier avec Choisir un fichier. Pour un CSV, choisissez également la bonne catégorie.
  4. Appuyez sur Prévisualiser et contrôlez les catégories ainsi que le nombre de lignes.
  5. Si tout est correct, utilisez Importer les lignes manquantes et confirmez. Vérifiez ensuite le résultat et les nouvelles fiches.
Ce que l’import fait réellement

Il ajoute les lignes absentes et conserve les lignes existantes. Il ne sert pas à corriger une fiche déjà enregistrée. La prévisualisation ne garantit pas que tous les liens entre les fiches seront acceptés lors de l’import.

Limites et fichiers séparés

Les fichiers acceptés sont Excel (.xlsx) et CSV (.csv), de 10 Mo maximum et 5 000 lignes par feuille à l’import. Les comptes de connexion, les QR codes personnels des professeurs et les fichiers des documents ne sont pas transférés par cette fonction. Un export Excel n’est donc pas une copie complète de toute l’application.

16

Activer la double authentification

Un code temporaire en plus de votre mot de passe.

Tous les utilisateurs
  1. Dans Mon profil, vérifiez votre adresse e-mail avec le lien reçu si nécessaire.
  2. Dans la rubrique Double authentification, choisissez Activer avec une application d’authentification.
  3. Ouvrez le lien d’activation reçu par e-mail. Il est valable 15 minutes.
  4. Sur votre téléphone, ouvrez une application d’authentification compatible, par exemple Google Authenticator. Ajoutez un compte et scannez le QR code affiché sur la page d’activation.
  5. Saisissez le code indiqué par votre application pour confirmer. Revenez ensuite à votre profil et rechargez-le pour vérifier le statut Activée.
À chaque nouvelle connexion

Saisissez votre identifiant et votre mot de passe, puis le code actuel dans Code de l’application d’authentification (si activé). Ce code change régulièrement ; utilisez celui affiché au moment de vous connecter.

Gardez votre téléphone accessible

Ne partagez ni le QR code d’activation ni vos codes temporaires. En cas de perte du téléphone, contactez l’école. Changer le mot de passe par e-mail ne retire pas le deuxième facteur.

Réinitialiser un mot de passe oublié

Recevoir un lien dans votre propre boîte e-mail.

Tous les utilisateurs
  1. Sur l’écran de connexion, choisissez Mot de passe oublié ?.
  2. Saisissez l’adresse e-mail enregistrée sur votre compte, puis Envoyer le lien de réinitialisation.
