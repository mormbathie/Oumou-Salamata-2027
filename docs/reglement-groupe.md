# Régler plusieurs factures

Dans **Factures & Paiements**, le comptable, le directeur ou l’administrateur peut :

1. Filtrer éventuellement les factures par classe ou statut.
2. Cocher les factures à régler, ou **Sélectionner toutes les factures impayées affichées**.
3. Cliquer sur **Régler la sélection**.
4. Vérifier les élèves, les factures et le montant total, puis choisir le mode de paiement et ajouter une référence ou une note si nécessaire.
5. Cliquer sur **Confirmer le règlement** après avoir effectivement reçu les fonds.

Le règlement couvre le solde restant de chaque facture, y compris les factures partiellement payées. Les factures déjà réglées ou annulées ne sont pas sélectionnables. La sélection globale respecte les filtres affichés : retirer les filtres pour sélectionner toutes les factures impayées.

Chaque facture conserve son propre paiement et son reçu, accessibles par les actions habituelles. Le nom du comptable est enregistré, ainsi qu’une trace du règlement groupé. Les paiements sont datés du jour de confirmation.

Si une facture a changé entre la sélection et la confirmation, aucun paiement du lot n’est enregistré. Actualiser et vérifier la nouvelle sélection avant de recommencer. Une caisse clôturée refuse également le règlement. Au maximum 1 000 factures peuvent être réglées dans un même lot.
